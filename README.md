# Анализ аномалий в журнале заявок на закупку

Этот репозиторий содержит решение задачи по поиску нетипичного поведения в синтетической выгрузке событий выполнения заявок на закупку.

## Структура репозитория
- `students.csv` — исходный журнал событий.
- `analysis_simple.py` — скрипт для анализа данных (написан на стандартной библиотеке Python, не требует установки pandas или других зависимостей).
- `anomalies.csv` — итоговый файл с найденными аномалиями (32 уникальных процесса).
- `report.md` — краткий отчет о методологии, критериях и результатах анализа.

## Как воспроизвести результат
1. Убедитесь, что у вас установлен Python 3.x.
2. Поместите все файлы в одну директорию.
3. Запустите скрипт из терминала:
   ```bash
   python analysis_simple.py
